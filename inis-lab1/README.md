# Inis Lab1 — AI-интервьюер

Мобильный кликабельный макет на HTML, CSS и JavaScript. Новые экраны используют размеры и векторные элементы предоставленных SVG-макетов Figma **390 × 844**. На узких экранах сохраняются пропорции. Существующие страницы и навигация сохранены.

## Запуск

Откройте `index.html` либо запустите сервер из папки `inis-lab1`:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000/pages/training.html` и нажмите «Начать тренировку».

Новые страницы используют локальные Manrope и Inter 3.19, соответствующие типографике SVG. Их отображение не требует Google Fonts. Лицензии находятся в `fonts/`.

## Переходы

| Действие | Результат |
| --- | --- |
| «Начать тренировку» | `training-question-1.html`, новый черновик |
| «Получить подсказку» | `training-question-2.html`, подсказка над тем же вопросом |
| «Понятно», Escape или клик вне подсказки | Назад к вопросу с сохранённым ответом |
| «Отправить ответ» или Ctrl+Enter / Cmd+Enter | Валидация и `training-results.html` |
| «Завершить сессию» | Результаты, в том числе без отправленного ответа |
| «Разобрать ответы» | Окно с текущим ответом и ориентиром для самопроверки |
| «К аналитике» или «Прогресс» | `analytics.html` |
| Нижнее меню результатов | Главная, тренировка, база, прогресс, профиль |
| Меню и колокольчик | `menu.html` и `profile-4.html` |

При прямом открытии страницы подсказки «Понятно» также возвращает к вопросу.

## Файлы

- `css/training-session.css` — стили вопроса, подсказки, результатов и разбора; остальные экраны не затрагиваются.
- `css/training-fonts.css`, `fonts/` — локальные шрифты и лицензии.
- `js/training-session.js` — общая разметка вопроса и шапки, валидация, черновик, переходы, диалоги и голосовой ввод.
- `images/icons/ic-rag-*.svg`, `images/icons/ic-results-*.svg` — оригинальные векторы макетов.
- `pages/training-question-1.html` — обновлённый вопрос.
- `pages/training-question-2.html`, `pages/training-results.html` — экраны вместо заглушек.
- `pages/training.html` — сброс черновика при начале новой тренировки.

## Форма и доступность

При отправке ответ обязателен: пустая строка и одни пробелы не принимаются. Лимит — 1000 символов, счётчик обновляется при вводе. Ошибка показана под полем, фокус возвращается в него. Завершение сессии не требует ответа.

Черновик и последний ответ сохраняются в `sessionStorage` текущей вкладки. При недоступном хранилище форма и переходы продолжают работать. Пользовательский ответ вставляется в разбор как текст, без исполнения HTML.

Микрофон использует `SpeechRecognition` / `webkitSpeechRecognition`. Если функция или разрешение недоступны, появляется сообщение с предложением ввести ответ с клавиатуры. Распознавание зависит от браузера и может требовать HTTPS или localhost и сетевого подключения.

Диалоги поддерживают Escape, удерживают клавиатурный фокус внутри окна и блокируют фон. При закрытии фокус возвращается к кнопке открытия.

## Данные макета

Это фронтенд-прототип. Значения 70%, 50%, 85%, 64%, +12%, номер вопроса и время 01:42 взяты из макета и не рассчитываются по ответу. Разбор показывает сохранённый ответ и фиксированный ориентир для самопроверки. AI-сервис не подключён.

## Ручная проверка

1. Введите текст, откройте подсказку и нажмите «Понятно»: ответ и счётчик сохраняются.
2. Отправьте пустой ответ и ответ из пробелов: появится ошибка без перехода.
3. Отправьте заполненный ответ: откроются результаты; разбор показывает введённый текст.
4. Начните новую тренировку и завершите её без ответа: старый ответ не попадает в разбор.
5. Проверьте кнопки результатов, нижнюю навигацию, меню и колокольчик.
6. Сравните экраны с SVG при размере окна 390 × 844 и масштабе браузера 100%.
